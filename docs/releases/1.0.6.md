# Ghost City RLT 1.0.6

## Changes since 1.0.5

- Added Fang's Recruiting Generator as an embedded preseason mod. Select its settings JSON in Toolbox; it runs before Transfer Wave, Rebalance, Pipelines, and the import.
- Added Fang results and backup details to the import log.
- Updated PocketScout Utilities to 0.9.10 for the current EA title update.
- Updated Transfer Wave to v2.0, including configurable top-two destination handling for prestige-cap exceptions.
- Fixed the portable build so required `madden-franchise` lookup data is included.
- Added a clean optional local-browser workflow: `setup-ghost-city-rlt.bat` once, then `run-ghost-city-rlt.bat` for later launches.

## Upgrade notes

For preseason imports with Fang enabled, select the Fang settings JSON in Toolbox before importing. Replace your old portable exe with the new one; your existing tracker data remains intact.
